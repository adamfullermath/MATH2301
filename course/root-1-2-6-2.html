    2.

    Calculate the following limits.
    🔗

    (a)

    \(\lim_{x\rightarrow 2}\frac{x^2-4}{x-4}.\)
    🔗
    Solution.
    Note, if \(f(x) = \frac{x^2-4}{x-4}\text{,}\) \(f(x)\) is continuos at \(x=2\) (we are not dividing by \(0\) at \(x=2\)). Thus
    \begin{equation*} \lim_{x\rightarrow 2}\frac{x^2-4}{x-4} = \frac{(2)^2-4}{2-4} =\frac{0}{-2}=0. \end{equation*}
    🔗
    🔗
    🔗

    (b)

    \(\lim_{x\rightarrow 0}x^2 \sin\left(\frac{1}{x}\right).\)
    🔗
    Solution.
    Note \(-1\leq \sin(1/x)\leq 1\) for all \(x \neq 0\text{.}\) Multiplying across by \(x^2\) (which is never negative), we have
    \begin{equation*} -x^2 \leq x^2 \sin(1/x) \leq x^2. \end{equation*}
    Since \(\lim_{x\rightarrow 0} x^2 = 0 = \lim_{x\rightarrow 0} -x^2\text{,}\) it follows by the Squeeze theorem that
    \begin{equation*} \lim_{x\rightarrow 0}x^2 \sin(1/x) = 0. \end{equation*}
    🔗
    🔗
    🔗

    (c)

    \(\lim_{x\rightarrow 1}\frac{x^2 + 2x}{3x+1}\)
    🔗
    Solution.
    This follows the same reasoning as part (a). The function \(f(x) = \frac{x^2 + 2x}{3x+1}\) is continuous and defined at \(x=1\text{,}\) and hence
    \begin{equation*} \lim_{x\rightarrow 1}\frac{x^2 + 2x}{3x+1}= \frac{(1)^2 +2(1)}{3(1)+1}=\frac{3}{4}. \end{equation*}
    🔗
    🔗
    🔗

    3.

    Calculate the following limits.
    🔗

    (a)

    \(\lim_{x \rightarrow \infty}\frac{2x^3 - 7x +5}{2x^3 +3x^2 + 1}\)
    🔗
    Solution.
    Dividing top and bottom by the \(x^3\) (the highest power of \(x\) in the denominator) we get
    \begin{align*} \lim_{x \rightarrow \infty}\frac{2x^3 - 7x +5}{2x^3 +3x^2 + 1} \amp= \lim_{x \rightarrow \infty}\frac{(2x^3 - 7x +5)\cdot \frac{1}{x^3}}{(2x^3 +3x^2 + 1)\cdot \frac{1}{x^3}} \\ \amp = \lim_{x \rightarrow \infty}\frac{2 - \frac{7}{x^2} +\frac{5}{x^3}}{2 +\frac{3}{x} + \frac{1}{x^3}}\\ \amp = \frac{\lim_{x\rightarrow\infty}2 - \lim_{x\rightarrow\infty} \frac{7}{x^2} + \lim_{x\rightarrow\infty}\frac{5}{x^3}}{\lim_{x\rightarrow\infty} 2 +\lim_{x\rightarrow\infty} \frac{3}{x} + \lim_{x\rightarrow\infty}\frac{1}{x^3}}\\ \amp= \frac{2+0+0}{2+0+0} \\ \amp = 1. \end{align*}
    🔗
    🔗
    🔗

    (b)

    \(\lim_{x \rightarrow \infty} 2x^3 - 7x +5\)
    🔗
    Solution.
    \(\lim_{x\rightarrow \infty}2x^3=\infty.\) For large \(x\text{,}\) \(x^3\) dominates the \(-7x\) and \(+5\) terms. That is, \(x^3\) goes to infinity far quicker than \(-7x\) goes to \(-\infty\text{.}\) Thus \(\lim_{x \rightarrow \infty} 2x^3 - 7x +5 = \infty.\)
    🔗
    🔗
    🔗

    (c)

    \(\lim_{x \rightarrow \infty} \cos(x)\)
    🔗
    Solution.
    Cosine oscillates between \(1\) and \(-1\) infinitely often as \(x\) goes to infinity. More precisely, \(\cos(2n\pi)=1\) and \(\cos((2n+1)\pi)=-1\) for all integers \(n\text{.}\) Thus, \(\cos(x)\) does not approach any one value as \(x\) increases. Hence \(\lim_{x\rightarrow \infty}\cos(x)\) does not exist.
    🔗
    🔗
    🔗

    4.

    Consider the parabola \(y = 4x - x^2\text{.}\)
    🔗

    (a)

    Find the slope of the tangent line to the parabola at the point \((1,3).\)
    🔗
    Solution.
    Using the power rule, we have
    \begin{align*} \frac{dy}{dx} \amp = 4 - 2x. \end{align*}
    Hence, the slope at \(x=1\text{,}\) is
    \begin{equation*} \left.\frac{dy}{dx}\right|_{x=1} = 4 - 2(1) = 2. \end{equation*}
    🔗
    🔗
    🔗

    (b)

    Find the equation of the tangent line to the parabola at the point \((1,3).\)
    🔗
    Solution.
    The equation of a line through a point \((x_0,y_0)\) with slope \(m\) is
    \begin{equation*} y = m(x-x_0) + y_0. \end{equation*}
    Here, we want a line through \((1,3)\) (from the question), with slope \(m=2\) (from part (a)). Hence the equation of tangent line through \((1,3)\) is
    \begin{equation*} y = 2(x-1) + 3, \end{equation*}
    Or
    \begin{equation*} y = 2x + 1. \end{equation*}
    🔗
    🔗

    5.

    Let \(f(x) = x^2 - 2x\text{.}\) Use the definition of the derivative (i.e. the limit formula for derivatives) to calculate \(f'(2)\text{.}\)
    🔗
    Solution.
    The derivative \(f'(x)\) is given by,
    \begin{equation*} f'(x) = \lim_{h\rightarrow 0}\frac{f(x+h)-f(x)}{h}. \end{equation*}
    Thus,
    \begin{align*} f'(x) \amp = \lim_{h\rightarrow 0}\frac{[(x+h)^2 - 2(x+h)] - [x^2-2x]}{h}. \\ \amp =\lim_{h\rightarrow 0}\frac{[x^2+2xh + h^2 - 2x-2h] - [x^2-2x]}{h} \\ \amp =\lim_{h\rightarrow 0}\frac{2xh + h^2-2h}{h} \\ \amp = \lim_{h\rightarrow 0} 2x + h -2\\ \amp = 2x -2. \end{align*}
    That is,
    \begin{equation*} f'(x) = 2x-2. \end{equation*}
    🔗
    🔗

    6.

    Calculate the derivative for each of the following functions. (You can use any method to find your answer.)
    🔗

    (a)

    \(f(x) = 2x^3 - x^2 + 5x +7.\)
    🔗
    Solution.
    Using the power rule
    \begin{equation*} f'(x) = 2(3x^2)-2x + 5 + 0. \end{equation*}
    Hence
    \begin{equation*} f'(x) = 6x^2 - 2x + 5. \end{equation*}
    🔗
    🔗
    🔗

    (b)

    \(g(t) = \frac{t+1}{\sqrt{t}}.\)
    🔗
    Solution 1.
    We can rewrite \(g(t)\) as
    \begin{equation*} g(t) = t^{1/2} + t^{-1/2}. \end{equation*}
    Using the power rule to differentiate we get
    \begin{equation*} g'(t) = \frac{1}{2}t^{-1/2} + (\frac{-1}{2}t^{-3/2}). \end{equation*}
    So
    \begin{equation*} g'(t) = \frac{1}{2\sqrt{t}} - \frac{1}{2t^{3/2}} = \frac{t-1}{2t^{3/2}}. \end{equation*}
    🔗
    🔗
    Solution 2.
    Though it wasn’t expected on this exam, one can also use the quotient rule to evaluate \(g'(t)\text{.}\) Using the quotient rule we get
    \begin{align*} g'(t) \amp = \frac{(1)\sqrt{t}-(t+1)\frac{1}{2\sqrt{t}}}{[\sqrt{t}]^2} \\ \amp = \frac{\sqrt{t}}{t} - \frac{t+1}{2t^{3/2}}\\ \amp = \frac{1}{\sqrt{t}}- \frac{t+1}{2t^{3/2}}\\ \amp = \frac{t-1}{2t^{3/2}}. \end{align*}
    Note, this is the same answer we got using the power rule.
    🔗
    🔗

    7.

    Below is the graph of a function \(f(x)\) for \(x\) between \(-2\) and \(4\text{.}\) That is, \(x\) is in the interval \([-2,4].\) Answer the following questions based on the graph.
    🔗
    🔗

    (a)

    At which \(x\)-values is \(f\) not continuous?
    🔗
    Solution.
    The function \(f(x)\) is not continuous at
    • \(x = 0\) (a jump discontinuity); and
      🔗
    • \(x = 3\) (a removable discontinuity).
      🔗
    🔗
    🔗
    🔗

    (b)

    At which \(x\)-values is \(f\) not differentiable?
    🔗
    Solution.
    The function \(f\) is not differentiable at
    • \(x = 0\) and \(x = 3\) (since \(f\) is not continuous at \(x=0\) or \(x = 3\)); and
      🔗
    • \(x = 2\) (since \(f(x)\) has a cusp at \(x=2\text{.}\))
      🔗
    🔗
    🔗
    🔗

    (c)

    On which intervals is the derivative \(f'(x)\) positive?
    🔗
    Solution.
    \(f'(x)\) is positive where \(f(x)\) is increasing. Thus, \(f'(x)\) is positive on the intervals
    \begin{equation*} (-2,0) \cup (2,3) \cup (3,4). \end{equation*}
    🔗
    🔗
    🔗

    (d)

    On which intervals is the derivative \(f'(x)\) negative?
    🔗
    Solution.
    \(f'(x)\) is negative where \(f(x)\) is decreasing. Thus, \(f'(x)\) is negative on the interval
    \begin{equation*} (0,2). \end{equation*}
